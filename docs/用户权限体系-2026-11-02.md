# 用户权限体系（细粒度授权）

## 一、要解决什么

原系统只有 `admin` / `user` 两种角色，判定方式是 `get_current_admin` 一处拦截。问题是：

- 要么什么都能干，要么什么都不能干。给合规专员开「知识库管理」，就不得不把他变成管理员，
  顺带给了他模型配置（含 API Key）、用户管理的权限
- 没有账号禁用能力，离职或外部演示账号只能靠删除

## 二、设计

### 角色不变，叠加权限点

- `role` 仍是 `user` / `admin` 两级，不做角色膨胀
- 普通用户额外能力用**权限点**授予，管理员**恒拥有全部**
- 权限点固定枚举（不接受任意字符串），前后端共用同一份 key

| 权限点 | 名称 | 覆盖范围 |
|---|---|---|
| `knowledge:manage` | 知识库管理 | 知识文档增删改查、风险类别维护 |
| `template:manage` | 审查模板 | 模板的创建/修改/删除（读取开放给所有登录用户） |
| `stats:view` | 用量统计 | LLM 调用次数、token、耗时 |
| `audit:view` | 审计日志 | 全站操作审计 |
| `user:manage` | 用户与权限 | 查看用户、授予权限、禁用账号、重置密码 |

**`模型配置` 不在可授权范围**：它存的是 API Key，属于密钥管理，始终 `role=admin` 独占。
界面上也明确写了这一点，避免"以为授权了其实没有"。

### 权限不进 JWT

JWT 只放身份（`sub` / `username` / `role`）。`get_current_user` 每次请求回查一次
`users` 表（主键查询），把最新权限填进 `TokenPayload`。

代价是每请求一次主键查询；换来的是：

- 授权后**对方不用重新登录**立刻生效
- 回收权限**立即失效**，不用等 token 过期
- 禁用账号**立即踢下线**（已签发的 token 一并作废）

对毕设这种规模，这个取舍明显划算；若将来 QPS 上来了，加一层 Redis 缓存权限即可。

### 后端校验

```python
@router.get("/knowledge")
async def list_knowledge(current: TokenPayload = Depends(require_permission("knowledge:manage"))):
    ...
```

`require_permission(*keys)` 是依赖工厂：管理员直接放行，普通用户需命中任一权限点，
否则返回 403 `缺少权限：knowledge:manage`。

## 三、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/users` | 用户列表（角色、权限、状态、注册时间） |
| GET | `/api/admin/users/permissions` | 可授予的权限点目录 |
| PUT | `/api/admin/users/{id}/permissions` | 全量覆盖权限列表 |
| PUT | `/api/admin/users/{id}/status` | 启用 / 禁用 |
| PUT | `/api/admin/users/{id}/password` | 重置密码 |

## 四、安全边界（实测）

| 场景 | 结果 |
|---|---|
| 普通用户访问未授权接口 | 403 `缺少权限：xxx` |
| 授权后（同一 token，不重新登录） | 200，立即生效 |
| 回收权限后 | 403，立即失效 |
| 提交不存在的权限点 | 400 `未知权限点: ['hack:all']` |
| 对管理员账号改权限 | 400 `不能对管理员账号执行「修改权限」` |
| 禁用后使用旧 token | 403 `账号已被禁用` |
| 禁用后重新登录 | 403 `账号已被禁用，请联系管理员` |
| 禁用自己 | 400 `不能禁用自己的账号` |
| 普通用户访问模型配置 | 403 `需要管理员权限`（授权也拿不到） |

> 登录时先校验密码再校验禁用状态，避免用「已被禁用」这个提示帮人枚举用户名。

## 五、前端

- `stores/user.js` 增加 `permissions` 与 `hasPerm(key)`，管理员恒为 `true`
- 路由 `meta.perm` 守卫；`meta.admin` 保留给模型配置这类不可授予页面
- 侧边栏菜单按权限点显示，不再看 `role === 'admin'`
- `App.vue` 挂载时拉一次 `/auth/me`，以服务端为准刷新角色与权限（管理员在别处改了权限，刷新页面就能看到菜单变化）
- 新增「用户与权限」页：列表 + 权限勾选弹窗 + 禁用 + 重置密码

## 七、验收记录

- 注册新用户 → `role=user`、`permissions=[]`
- 管理员授予「知识库管理 + 用量统计」→ 该用户同一 token 下两个接口 200、其余仍 403
- 「用户与权限」页勾选保存 → 列表即时显示标签，侧边栏出现对应菜单
- 普通用户登录后侧边栏仅 5 项（首页/任务中心/法律问答/知识库管理/风险类别），无「审查模板/模型配置/审计日志/用量统计/用户与权限」，也无「管理员」标签
- 直接访问 `/admin/model-config`、`/admin/users` 被守卫弹回首页
- 审计记录：`user.permission`、`user.status` 两条动作类型，详情为中文权限名
